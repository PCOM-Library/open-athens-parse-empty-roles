# open-athens-parse-empty-roles
Scan OpenAthens accounts for empty roles and output that list.
## Directions for Use
1. Open OpenAthens and go to Accounts.
2. Select the PCOM tab and adjust view to show 100 results (speeds up the processing).
3. Open Developer Tools (F12) and select console.
4. Paste the contents of script.js into the console and press enter.
5. Copy the results.
